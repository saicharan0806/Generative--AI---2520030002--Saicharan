# Golden set questions and expected answers
**Objective** : The main objective of this experiment is evaluate how the model is performing. The user will give a set of questions and expected answers and AI model will compare both answers and give the score.

## Project Folder Structure : 
  1. **golden-set.json** : contains set of 30 questions and expected answers for testing the model. The fields are "id", "question", "expected_answer", "keywords", "source".
  2. **requirements.txt** : used to Install the required libraries for this experiment.
  3. **Main.py** : This is the actual executable code. It loads the questions and send them to llamma3.2
     Questions -> llamma3.2 -> Model will answer the questions -> calculate scores -> save results in the form of .csv.
## How to run it??
  1. Install the requirements using the command called
     **pip install -r requirements.txt**
  2. Run the main programm in the terminal with command called **python filename.py**.
## Expected output
- loads the all questions

- send the questions one by one to llamma

- it will display the scores.

- then it will give the score by seeing the keyword matches.

- creates a .csv file.
